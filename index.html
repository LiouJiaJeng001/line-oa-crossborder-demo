跨時區 LINE 客服工單交接示範

台灣客服白天在 LINE 收到需求，美國客服上班時才接手。這個頁面示範在 LINE 官方帳號後面加一層工單：訊息進來自動抽出取件地、收件地、品項、重量、時效，產生工單編號，台美共用同一份看板並列兩地時間，交接時自動生成英文摘要，狀態一變就推回客戶的 LINE。

示範用途 資料全為虛構 非任何客戶的實際畫面 非已完成的產品

1. 客戶在 LINE 上說了什麼

選一則示範訊息，或直接改寫下面的文字，按「解析並建單」。抽取用的是關鍵字與樣式比對，改了字就會抽到不一樣的結果。抽不到的欄位會標成需人工補，而且不會沿用上一則訊息的值——方向、時效、重量、材積只要沒講，就是空的，費用也不會試算。

2. 人工可覆寫的參數

抽取結果會填進這裡；客服可以改。任何一格改動，下面的計費重、費用、時效、交接等待時間與英文摘要都會跟著重算。方向與時效抽不到時會停在「未判定」，要由客服選了才會出現報價。

3. 台灣端：LINE 聊天室

台灣客服照樣在 LINE 上對話，不改工作習慣。工單狀態一變，就在同一個聊天室推播給客戶。

    實際導入會怎麼做
    
  
    正式版會以 LINE Messaging API 的 Webhook 接收訊息，每位使用者一個獨立聊天室，工單存進資料庫並保留修改紀錄；欄位抽取採規則先行、模糊的敘述再交給模型判讀，且一律留人工覆寫。狀態變更透過 Push Message 回客戶的 LINE，並保留人工接手與 AI 自動回覆的切換。
    

  
    範圍上會分兩階段：第一階段（MVP）是 LINE 接入、欄位擷取、工單編號、一組後台登入給台灣客服補正確認、狀態自動推播；本頁示範的台美雙邊看板與英文交接摘要屬第二階段，屆時台美各一組登入、看板需登入才能存取。細分到每位客服的角色權限（誰能改狀態、誰只能看）與操作紀錄是後續項目。是否回寫國際快遞的追蹤號、以及要不要串既有系統，會等確認美國端目前用什麼記單之後再定範圍。
